# المشتبه

لعبة ألغاز تحقيق عربية على شبكة تصل إلى ١٦×١٦. تطبيق ويب فقط.

**الحالة الحالية: جاهز للنشر — المستنتج، المولّد، مكتبة من ٢٥ قضية (منها ٤ شاهد كاذب)، واجهة لعب بهوية كاملة،
وحزمة نشر ثابتة.**

## النشر

```bash
npm run build      # يفحص المكتبة ثم يبني dist/ (نحو ١.١ ميغابايت، بلا اعتماديات)
npm run preview    # معاينة الحزمة على http://localhost:5180/
```

`dist/` موقع ثابت كامل: ارفعه كما هو إلى Cloudflare Pages أو Netlify أو Vercel أو GitHub Pages
(من جذر النطاق). يتضمن بيان تطبيق (قابل للتثبيت على الجوال) وعامل خدمة يجعله يعمل بلا إنترنت بعد أول زيارة.

## الشاهد الكاذب (المرحلة ٤)

نمط `lyingWitness`: بطاقة واحدة كاذبة هي بطاقة القاتل. المولّد يبني اللغز بلا بطاقة القاتل، ثم يضيف كذبة
مختارة تجتاز فحصًا رباعيًا آليًا (`lyingWitnessReport`): كل البطاقات معًا تؤدي لتناقض؛ بدون بطاقة الكاذب
تُحل بلا تخمين وتطابق الحل والكاذب هو القاتل؛ بدون بطاقة أي شاهد آخر لا تُحل (فلا يُتَّهم بريء)؛ والكذبة كاذبة
فعلًا على الحل. في الواجهة: لافتة النمط، زر «كذّب» يستثني بطاقة من فحص التناقض، وتلميح افتتاحي لا يفضح الكاذب.

## الهوية والفن (المرحلة ٣)

المسار المختار: **B — مرسوم برمجيًا بـSVG** في `web/art/`. لا أصول خارجية؛ كل شيء يُرسم من الشفرة بزاوية
نظر واحدة (من فوق) واتجاه ضوء واحد (الشمال الغربي):

- `floors.js` عشر أرضيات (سجّاد، بلاط، حجر، رمل، عشب، ماء، خشب، إسمنت، قش، رخام) بثلاث صيغ لكل منها لكسر التكرار.
  نوع الأرضية جزء من بيانات الغرفة في ملف القضية (`rooms[].floor`).
- `props.js` ٥٤ قطعة أثاث بخط واحد متسق، ورقة رموز واحدة تُدرج مرة وتُستدعى بالمرجع.
- `avatar.js` شخصيات مولّدة من أرقام الأفاتار: بشرة، شعر، لحية، ثوب/عباية، غترة/شماغ/طاقية/شيلة. لا رسم يدوي.
- عرضان لخريطة واحدة: **مشهد** (خامات وظلال وثلاث درجات إضاءة: نهار، غروب، ليل) و**مخطط** (ورق وحبر،
  عالي التباين، للاستنتاج والطباعة). التبديل بزر أو بمفتاح V، ولا شيء في المحرّك يعرف بالعرض.
- تأطير «ملف قضية»: رقم الملف، ختم شمعي للدرجة، ختم «أُغلقت القضية» عند الحل، وقائمة الملفات كصفحات دوسيه.
- الخريطة عربية: **العمود ١ أقصى اليمين**، الشمال أعلى، الشرق يمين الشاشة. المولّد لا يُخرج أدلة إحداثية
  («كنت في الصف ٩») إلا حين لا بديل مشهدي لها، والتلميحات تذكر الغرفة مع الخلية.
- دليل «كيف ألعب» بست خطوات يظهر أول مرة.

## جرّبها الآن

```bash
npm run dev          # خادم تطوير بلا اعتماديات
# ثم افتح http://localhost:5173/
```

الواجهة في `web/` تستورد المحرّك نفسه (`src/engine/`) في المتصفح بلا بناء ولا حزم.
نموذج التفاعل حسب القسم 08: بلا شخصية محدّدة، النقرة تبدّل ✗؛ مع شخصية محدّدة، النقرة تدوّر
قلم ← مثبّت ← فارغ، والتثبيت يحجب صفه وعموده تلقائيًا. البطاقة المخالفة تحمرّ دون منع الحركة،
والفحص لا يستشير الحل أبدًا. تراجع/إعادة، شطب البطاقات، تركيز الغرفة، ربط البطاقة بخلاياها،
سلّم تلميحات يُكشف درجة درجة، حفظ تلقائي، وتسليم يكشف القاتل عند الحل الصحيح فقط.

## الفكرة في سطرين

الشبكة خريطة مسرح الجريمة مقسّمة لغرف. كل شخصية في صف وعمود فريدين. اللاعب يقرأ
بطاقات الشهود ويضع الشخصيات على الخريطة. القاتل لا يُسأل عنه أبدًا: هو من ينتهي
في غرفة الضحية. والمبدأ الهندسي الحاكم: **كل لغز يُحل بالاستنتاج المباشر فقط**
(constraint propagation) بلا تخمين ولا تعداد، والمولّد **يبدأ بكل الأدلة الصادقة ثم يحذف**.

## التشغيل

```bash
npm test                                                   # ٢٠ اختبارًا (المستنتج + المولّد)
node src/cli/solve.js cases/case-001.json                  # ملخص + خريطة الحل
node src/cli/solve.js cases/case-001.json --trace          # + سلسلة الاستنتاج كاملة بأسبابها
node src/cli/solve.js cases/case-001.json --hints          # + سلّم التلميحات المضغوط
node src/cli/solve.js cases/case-001.json --minimal        # + فحص ضرورة كل دليل
node src/cli/solve.js cases/case-001.json --prune          # + اقتراح أصغر مجموعة أدلة

node src/cli/generate.js --size 16 --tier expert --seed 7  # قضية واحدة (تُكتب في cases/)
node src/cli/generate.js --size 8 --tier medium --dry      # توليد بلا كتابة
npm run generate:library                                   # مكتبة ٢٠ قضية بكل الدرجات + الفهرس
npm run verify:library                                     # بوابة النشر: معايير القبول لكل قضية
```

```text

  clues.js       كتالوج الأدلة والقواعد العامة — كل دليل قابل للفحص آليًا

  evaluate.js    فحص صدق الأدلة على توزيع كامل + استخراج القاتل
  propagate.js   المستنتج: قواعد الاستنتاج حتى النقطة الثابتة، مع أثر كامل، وقواعد قابلة للتقييد
  solver.js      حل، صعوبة مقاسة، ضرورة الأدلة، تقليم، سلّم التلميحات، معايير القبول

  random.js      مولّد عشوائي مُبذَّر (قابل لإعادة الإنتاج)

  content.js     ثلاث بيئات عربية (بيت، مزرعة، سوق): غرف، أشياء، أصناف، أسماء، عناوين
  layout.js      نمو الغرف من بذور متباعدة، الأشياء، الخلايا المحجوبة
  placement.js   حلّ عشوائي يحترم القواعد العامة وشرط الضحية
  clue-pool.js   كل الأدلة الصادقة + أوزان الحذف حسب الدرجة
  generate.js    ابدأ كاملًا ثم احذف؛ محاولات متعددة واختيار الأفضل
  serialize.js   ملف القضية الرئيسي + طبقة الترجمة + سلّم التلميحات
```

## قواعد الاستنتاج والصعوبة المقاسة

| القاعدة | ما تفعله | الدرجة |
| --- | --- | --- |
| unary / classRestriction | الأدلة الأحادية وقيود الصنف تصفّي المجالات دفعة واحدة | easy |
| rowCol | الشخصية المحسومة تحجب صفها وعمودها عن الجميع | easy |
| hiddenSingle | صف/عمود لا يمكن أن يشغله إلا شخص واحد | medium |
| relation | الأدلة الثنائية (بجانب فلان، نفس الغرفة، إزاحة صفوف/أعمدة) بمراجعة الدعم | medium |
| occupancy | وحده / وحده مع فلان / وحده مع القاتل / k أشخاص | hard |
| noEmptyRegion / regionQuota / pairwiseClass | القواعد العامة على الغرف | hard |

**الدرجة تُقاس لا تُقدَّر**: درجة القضية هي أدنى مجموعة قواعد تكفي لحلها. خبير = تحتاج قواعد
الإشغال والقواعد العامة، مع ٣ خطوات عامة فأكثر وسلّم تلميحات من ٨ درجات فأكثر.
المولّد يستهدف الدرجة بتقييد المستنتج أثناء التقليم بقواعد تلك الدرجة، فتُضمن قابلية الحل بها وحدها.

لا يوجد في المحرّك أي تفرّع أو تراجع. إن لم تكفِ القواعد، يعود «غير محلول» بدل أن يخمّن.

## سلّم التلميحات

يُولَّد من أثر الاستنتاج: درجة لكل حسم غير ميكانيكي، تحمل الحجوبات التي مهّدت له وما ترتّب عليه
من حسومات تلقائية («وهذا يحسم بدوره…»). قضية ١٦×١٦ تعطي نحو ١٢ درجة. مسودة عربية آلية لكل درجة
تُكتب في طبقة الترجمة ليعيد المؤلف صياغتها.

## إضافات على المواصفات

- `aloneWithKiller`: بطاقة الضحية كدليل يفهمه المستنتج ويُضاف تلقائيًا.
- `colOffset`: نظير `rowOffset` على الأعمدة، بصياغة «شرق/غرب» مثل «شمال/جنوب».
- `roomOccupancy`: تعميم «وحده» لأي عدد.
- الأشياء يمكن تكرار مفتاحها («بجانب طاولة» تعني أي طاولة). المراجع في JSON بالمفتاح أو الرقم.
- المولّد لا يضع في المجمّع أي دليل يفضح القاتل مباشرة (علاقته المباشرة بالضحية).
- معايير القبول (القسم 13) شفرة قابلة للتشغيل: `acceptanceReport` وبوابة `verify.js`.

## المكتبة

`cases/catalog.json` يفهرس القضايا: الهوية، الحجم، الدرجة المقاسة، الغرف، الأدلة، عدد درجات التلميح،
البيئة، والبذرة. كل قضية مولّدة تُعاد بنفس البذرة حرفيًا.
